## 📝 Prompts para Copywriting

### 1. Email de Venta Inicial
```
Eres un experto en ventas. Escribe un email corto (3-4 párrafos) 
para un cliente potencial que acaba de visitar nuestro sitio de [TU PRODUCTO].

Contexto:
- Nombre del cliente: [NOMBRE]
- Empresa: [EMPRESA]
- Producto que le interesó: [PRODUCTO]
- Beneficio principal: [BENEFICIO]
- CTA: Agendar llamada

Tono: Profesional pero amigable, SIN saludo inicial formal.
Formato: Solo el cuerpo del email.
```

**Ejemplo (Benja):**
```
Eres un experto en ventas. Escribe un email corto (3-4 párrafos) 
para un cliente potencial que acaba de visitar nuestro sitio de paneles solares.

Contexto:
- Nombre del cliente: Roberto
- Empresa: Roberto Propiedades Maui
- Producto que le interesó: Sistema de 8kW
- Beneficio principal: Ahorrar $200/mes en electricidad
- CTA: Agendar llamada

Tono: Profesional pero amigable, SIN saludo inicial formal.
Formato: Solo el cuerpo del email.
```

### 2. Seguimiento (Follow-up)
```
Escribe un follow-up corto para un cliente que no respondió el email inicial.
Debe ser amigable, NO agresivo.

Cliente: [NOMBRE]
Producto: [PRODUCTO]
Razón de contacto: No hizo compra
Oferta: [DESCUENTO O BONUS]
Máximo: 2 párrafos

Tono: Casual, como de un amigo.
```

### 3. Anuncio para Redes Sociales
```
Crea 5 anuncios cortos (máximo 150 caracteres cada uno) para Instagram 
que promuevan [PRODUCTO] a [AUDIENCIA].

Incluye:
- 2 anuncios enfocados en beneficio
- 2 anuncios con urgencia/scarcity
- 1 anuncio testimonial

Formato: Numerados, con emojis relevantes.
```

### 4. Titulares Persuasivos
```
Genera 10 titulares para un anuncio de Google Ads sobre [PRODUCTO].

Requisitos:
- Máximo 30 caracteres cada uno
- Deben incluir beneficio clave o oferta
- Deben ser para [AUDIENCIA OBJETIVO]

Incluye variaciones con:
- Números
- Urgencia
- Beneficios
- Oferta directa
```

## 📱 Prompts para Social Media

### 1. Plan de Contenido 30 Días
```
Soy [TU ROL] en [TU EMPRESA]. Crea un plan de 30 posts para TikTok/Instagram
que eduquen y vendan sobre [PRODUCTO].

Mi audiencia: [DESCRIPCIÓN DE QUIÉN COMPRA]
Tono: [FORMAL/CASUAL/DIVERTIDO]
Incluir:
- 50% contenido educativo
- 30% entretenimiento
- 20% promoción

Formato: Numerado con: 
[Día] - [Tema] - [Idea en 1 línea] - [Hook (primera frase)]

Ejemplo para Benja:
Soy especialista en paneles solares. Crea un plan de 30 posts para TikTok
que eduquen y vendan sobre paneles solares en Maui.

Mi audiencia: Propietarios de casas en Maui, 25-65 años
Tono: Casual, amigable, educativo
```

### 2. Scripts de Video
```
Escribe un script de 30-60 segundos para un video de TikTok/YouTube Shorts
sobre [TEMA].

Estructura:
- 0-5s: Hook (atrapa atención)
- 5-20s: Contenido principal
- 20-25s: Call to action

Tema: [TU TEMA]
Audiencia: [QUIÉN VE]
Objetivo: [VENDER/EDUCAR/ENTRETENER]

Formato: 
[00-05s] HOOK: ...
[05-20s] CONTENIDO: ...
[20-25s] CTA: ...
```

### 3. Hashtags Estratégicos
```
Dame los 20 mejores hashtags para posts sobre [TEMA] en [PLATAFORMA].

Incluye mezcla de:
- 5 hashtags populares (#1M+ posts)
- 10 hashtags medios (#100k-1M)

Tema: [TU TEMA]
Plataforma: [TikTok/Instagram/YouTube]
Objetivo: [VIRALIDAD/CONVERSIÓN/ENGAGEMENT]
```

## 📊 Prompts para Análisis y Datos

### 1. Analizar Tendencias
```
Analiza estos datos de mi negocio de [INDUSTRIA]:

DATOS:
- Enero: [NÚMERO] clientes, [MONTO] pesos
- Febrero: [NÚMERO] clientes, [MONTO] pesos
- Marzo: [NÚMERO] clientes, [MONTO] pesos
- Abril: [NÚMERO] clientes, [MONTO] pesos

Necesito:
1. ¿Cuál es la tendencia?
2. ¿Qué cambió entre meses?
3. 3 acciones para mejorar en mayo

Formato: Corto y directo.
```

### 2. Competitive Analysis
```
Analiza a mi competencia. Dime:

Mis competidores:
- [Nombre] - [Descripción]
- [Nombre] - [Descripción]
- [Nombre] - [Descripción]

¿Cuáles son mis ventajas vs ellos?
¿Dónde me están ganando?
¿Cómo puedo diferenciame?

Contexto: Vendo [PRODUCTO] a [AUDIENCIA] en [UBICACIÓN]
```

## 🎯 Prompts para Automatización y Procesos

### 1. Crear un Proceso
```
Ayúdame a crear un proceso automatizado para [OBJETIVO].

Contexto:
- Frecuencia: [DIARIA/SEMANAL/MENSUAL]
- Herramientas disponibles: [ZAPIER/MAKE/GOOGLE FORMS/etc]
```

## 🎓 Prompts para Aprendizaje

### 1. Explicar Conceptos
```
Explícame [CONCEPTO DE IA] como si tuviera 10 años.

Requisitos:
- Máximo 100 palabras
- Usa analogías de la vida real
- Incluye 1 ejemplo práctico
- Nada de jerga técnica

Ejemplo: "Explícame qué es un LLM como si tuviera 10 años"
```

### 2. Crear un Curso Mini
```
Crea un mini-curso de 4 semanas sobre [TEMA].

Formato:
- Semana 1: Conceptos básicos
- Semana 2: Herramientas y práctica
- Semana 3: Proyecto pequeño
- Semana 4: Proyecto real

Para cada semana:
- 3-5 objetivos de aprendizaje
- 2 ejercicios prácticos
- Tiempo estimado: 3-5 horas

Tema: [TU TEMA]
Audiencia: [PRINCIPIANTES/INTERMEDIOS]
```

## 🔧 Prompts para Copywriting Específico

```
Escribe el copy para la página de inicio de [PRODUCTO/SERVICIO].

Secciones:
1. Headline (máx 10 palabras)
2. Subheading (máx 20 palabras)
```

## 💡 Tips para Mejores Prompts

### ✅ Haz tus prompts ESPECÍFICOS
```
❌ Malo: "Dame ideas de negocios"
✅ Bueno: "Dame 5 ideas de negocios online que pueda empezar 
con $100 de inversión, trabajando máximo 10 horas/semana, 
dirigido a gente que ya trabaja"
```

### ✅ Añade CONTEXTO
```
❌ Malo: "Escribe un email"
✅ Bueno: "Escribe un email de venta para un cliente que acaba 
de descargar mi lead magnet sobre paneles solares, 
no ha respondido en 3 días, vive en Maui, 
y el precio del producto es $5000"
```

### ✅ Especifica el FORMATO
```
❌ Malo: "Crea contenido"
✅ Bueno: "Crea 5 posts de 280 caracteres máximo con emojis 
para Instagram Stories sobre energía solar renovable"
```

### ✅ Dale EJEMPLOS
```
❌ Malo: "Genera emails"
✅ Bueno: "Genera 3 emails como este:
'Hola [NOMBRE], sin ataduras. Prueba gratis por 7 días. 
Si no te gusta, cancelación instant. ¿Probamos?' 
Pero para [MI PRODUCTO]"
```

## 🎯 Secuencia de Prompts Recomendada

Si quieres vender algo, sigue este orden:

1. **Primero**: Crea tu Proposición de Valor
   ```
   "¿Por qué debería alguien comprar [PRODUCTO] en lugar de [ALTERNATIVA]?
   Dame 3 razones claras y 1 métrica de éxito."
   ```

2. **Segundo**: Genera Ideas de Contenido
   ```
   "Dame 10 ideas de videos/posts que muestren las 3 razones anteriores"
   ```

3. **Tercero**: Crea el Copy de Venta
   ```
   "Escribe el email de venta basado en estas 3 razones..."
   ```

4. **Cuarto**: Automatiza
   ```
   "¿Cómo automatizo enviar este email a nuevos leads automáticamente?"
   ```

5. **Quinto**: Optimiza
   ```
   "¿Cómo puedo mejorar esta estrategia? 
   ¿Qué métrica debería medir?"
   ```
